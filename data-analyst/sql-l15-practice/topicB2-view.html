Analyst challenge · Build the query

Add the calculated field

Show a unit price after discount — the line total shared across the quantity ordered.

CREATE VIEW vSaleFullDetails AS SELECT h.SalesOrderID, d.OrderQty, () AS UnitPriceAfterDiscount, d.LineTotal FROM Sales.SalesOrderDetail d JOIN Sales.SalesOrderHeader h ON h.SalesOrderID = d.SalesOrderID

Analyst challenge · Find the bug

A View that will not create

This grouped view fails to create. Click the one clause that is not allowed inside a view.

CREATE VIEW vSalePerYearSeller AS SELECT YEAR(h.OrderDate) AS Yr, h.SalesPersonID, SUM(d.LineTotal) AS Total FROM Sales.SalesOrderDetail d JOIN Sales.SalesOrderHeader h ON h.SalesOrderID = d.SalesOrderID group by YEAR(h.OrderDate), h.SalesPersonID order by Total desc
