Practice 1 · String functions

What does LEFT return?

SELECT LEFT('Road-150', 4)

A scalar function reshapes one value. LEFT(text, n) returns the first n characters.

Practice 2 · Date functions

How many days between the two dates?

SELECT DATEDIFF(day, '2023-10-26', '2023-10-28')

DATEDIFF(part, start, end) returns the gap between two dates in the unit you name. (Related: DATEPART, YEAR, MONTH pull one part out of a date.)
