Combine & classify: UNION & CASE WHEN

Practice 1 · UNION

Combine two result sets

SELECT Region FROM NorthStores UNION SELECT Region FROM WestStores

Query 1 returns North, South, East. Query 2 returns South, East, West. Click every region in the UNION result.

Region

Practice 2 · UNION ALL

Same two queries, but with UNION ALL. How many rows now?

SELECT Region FROM NorthStores UNION ALL SELECT Region FROM WestStores

Query 1 returns 3 rows, Query 2 returns 3 rows.

Practice 3 · CASE WHEN order

First true wins. What band does a SubTotal of 300 get?

CASE WHEN SubTotal < 10000 THEN 'B' WHEN SubTotal < 500 THEN 'A' ELSE 'C' END

Conditions are checked top to bottom, and the first true one wins.
