05

Minimum-controls checklist

These are the controls that have to be in place before anything gets built. You are not ticking them off now: at this stage there is no system to check them against. Read them, then write which ones your case already answers, which are still open, and who would own each.

  • Data classification completed for every source
  • Data owner identified for every source
  • User roles identified
  • Allowed / forbidden data clearly defined
  • External tool/vendor use has been checked
  • Human approval points defined
  • Logging and access recording planned
  • Model output handling defined
  • Escalation path to InfoSec/DPO exists
  • No real identifying data used in testing
