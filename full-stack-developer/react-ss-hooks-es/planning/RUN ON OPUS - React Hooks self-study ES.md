Rules for the films:

- **Language:** neutral Latin-American Spanish, `tú`. Code identifiers stay in English (`useState`, `setCount`). Comments inside code may be Spanish.
- **What the screen shows:** code as typeset code cards (the line being discussed highlighted) and the output or console next to it.
  - **No drawn VS Code, browser or DevTools chrome.** That is a Wawiwa video rule.
  - Where the real editor is truly needed, cut a few seconds from the original MP4 and lay the Spanish narration over it. Say in the storyboard where and why.
- **Narration:** tells a small story (one learner building one small app across the five films), not a dictation of keystrokes. The English videos dictate syntax ("open parenthesis, close parenthesis"). Do not carry that over. Read `wawiwa-video` `references/writing-a-film.md` first.
- **No names:** no partner institution names and no Wawiwa SME names on screen or in narration.
- **Ending:** each film ends on the practice card, which points to its practice below the video.
