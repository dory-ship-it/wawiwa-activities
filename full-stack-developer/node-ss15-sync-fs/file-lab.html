          What you just saw
          
    
          You predicted  lines right, and you ran the code yourself. Here is what to take back to the lesson:
          
    
            
      
          • 
        
        mkdirSync creates a directory
        It throws an error if the directory exists, and the script stops there.
      
            • 
      
          • 
        
        writeFileSync creates or overrides
        It creates the file if it does not exist, and replaces all its content if it does.
      
            • 
      
          • 
        
        Every Sync call makes Node wait
        Nothing else runs until it finishes. That is what "blocks the event loop" means. You will see why it matters later in this self-study.
