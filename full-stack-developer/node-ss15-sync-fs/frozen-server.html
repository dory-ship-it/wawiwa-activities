    You predicted right. The lesson says it in two lines:

    Sync operations: Block the entire Node process. Freeze server handling.

    Acceptable for: Scripts. Setup tasks. Learning.

    Sync is fine
    • Creating the logs folder once, before the server opens
    • A one-time script
    • Practicing fs, like in this lesson
    Avoid sync
    • Reading a file while users are waiting
    • Writing a log line on every request
    • Anything that runs inside request handling
