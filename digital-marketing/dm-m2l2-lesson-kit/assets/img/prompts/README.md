# Image prompts, DM M2 L2 lesson (Phase 1)

One prompt file per image slot. Every prompt ends with the same "Shared photographic language" block, so the whole
course gets one consistent look (digital marketing work: a marketer's desk, dashboards, search results, a phone with
a social feed; realistic editorial photography; no stock grins; no text in the image; no real brands or logos).
